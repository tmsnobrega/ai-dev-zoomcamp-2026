# ReportReady

ReportReady helps analysts check recurring CSV submissions before combining
them into a report or dashboard. It tracks expected submissions, runs clear
data-quality checks, and prevents approval until every required file passes.

## Current status

The initial Cloudflare Worker was deployed on 3 September 2026 as a deployment
smoke test. Application code and the D1 database will be added after the first
schema and application scaffold are reviewed.

Starter URL: <https://reportready.tmsnobrega.workers.dev>
